# Portafolio web — Leidy Lorena Ortiz

Sitio web personal para presentar el perfil profesional de una árbitra de fútbol.

## Archivos

- `index.html`: estructura y contenido.
- `style.css`: diseño adaptable, colores y animaciones.
- `script.js`: menú móvil, animaciones y visor de fotografías.
- `images/`: fotografías personales.

## 1. Agregar tus fotografías

Copia tus imágenes reales dentro de la carpeta `images` y usa estos nombres:

| Nombre del archivo | Uso |
|---|---|
| `portada.jpg` | Foto principal de la portada |
| `foto-1.jpg` | Primera foto de la galería |
| `foto-2.jpg` | Segunda foto de la galería |
| `foto-3.jpg` | Tercera foto de la galería |
| `contacto.jpg` | Foto de fondo de la sección de contacto |

Puedes usar fotografías JPG o convertirlas a JPG antes de agregarlas. Mantén exactamente los nombres para que aparezcan automáticamente. No se incluyen fotos personales: debes añadir las tuyas.

## 2. Personalizar el contenido

Abre `index.html` y modifica:
- La presentación de “Sobre mí”.
- Formación, experiencia, torneos y logros.
- El correo del botón de contacto (`TU-CORREO@EJEMPLO.COM`).
- Los enlaces de redes sociales si deseas agregarlos.

Completa únicamente información verdadera. El diseño deja textos guía donde faltan datos.

## 3. Ver el sitio en Visual Studio Code

1. Descomprime la carpeta.
2. Abre Visual Studio Code.
3. Selecciona **File → Open Folder** y abre `leidy-lorena-referee-portfolio`.
4. Abre `index.html` en el navegador. También puedes instalar la extensión **Live Server**, hacer clic derecho sobre `index.html` y seleccionar **Open with Live Server**.

## 4. Publicar gratis con GitHub Pages

1. Crea o inicia sesión en https://github.com/
2. Crea un repositorio nuevo, por ejemplo `leidy-lorena-referee`.
3. Sube todos los archivos y la carpeta `images` (con tus fotos).
4. En el repositorio abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`. Guarda.
7. Espera a que GitHub Pages publique el sitio. La dirección será similar a:
   `https://TU-USUARIO.github.io/leidy-lorena-referee/`

## 5. Actualizar la página

Cada vez que edites y subas cambios a la rama `main`, GitHub Pages volverá a publicar el sitio.

## Nota

El formulario de contacto no está conectado a un servicio de envío. En esta versión, el botón de contacto abre el programa de correo del visitante mediante `mailto:`. Sustituye el correo de ejemplo por el tuyo.
